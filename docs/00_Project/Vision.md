# Vision

## Vision Statement

Project GeeNi is a premium digital wedding experience that transforms from an invitation into a lifelong archive of memories.

The website should remain useful before, during, and long after the wedding.

---

# Mission

Create the most elegant Indian wedding website ever built.

The goal is not to have the most features.

The goal is to create the best experience.

---

# Core Principles

## Emotion Before Information

Guests should feel welcomed before they start reading details.

---

## Simplicity is Luxury

Whitespace is a feature.

Every screen should have breathing room.

---

## Photography First

The design should elevate memories rather than compete with them.

---

## Mobile First

Most guests will arrive from a WhatsApp link.

The mobile experience is the primary experience.

---

## Timeless

The website should still look beautiful ten years from now.

Avoid trendy UI patterns that age quickly.

---

# Success Criteria

Guests can find any information in under 30 seconds.

Photo uploads take less than one minute.

The couple receives high-quality memories from guests.

The website transitions smoothly from invitation to memory archive.

---

# Non Goals

This project is not a social media platform.

It is not an event management application.

It is not a generic wedding template.

---

# Product Pillars

1. Elegance
2. Simplicity
3. Performance
4. Accessibility
5. Emotional Design
6. Longevity

Every feature should strengthen at least one pillar.

If it does not, it should not be built.

---

# Guiding Question

Before implementing any feature, ask:

"Does this make the guest experience better?"

If the answer is no,

do not build it.
