# Design Tokens

## Purpose

Provide a single source of truth for all visual values.

---

# Philosophy

Elegant.

Calm.

Premium.

Timeless.

Whitespace is a feature.

---

# Responsive Scale

Mobile

Base

Tablet

---

# Component Rules

Every component must consume design tokens.

Hardcoded values are prohibited unless documented.

---

# Tailwind Mapping

Design tokens should map to Tailwind theme values.

No inline styles.

No arbitrary colors unless approved.

---

# Future

All tokens should eventually be exported as JSON for Figma synchronization.
