# Mobile First

## Philosophy

Design for mobile first.

Desktop enhances.

Never the opposite.

---

# Breakpoints

Mobile

320–767px

Tablet

768–1023px

Desktop

1024+

Large Desktop

1440+

---

# Mobile Rules

Thumb-friendly.

Bottom navigation.

Single-column layout.

Cards stack vertically.

Buttons minimum height

48px.

---

# Performance

Initial JS

<200KB

Images lazy loaded.

Modern image formats.

Offline caching where possible.
